# Modern Terminal 디자인 가이드

## 목적

이 문서는 Agent Dock의 `modern dark + terminal` 디자인 기준을 정의한다.

피그마 파일 없이 사용자 설명과 확인한 레퍼런스 스타일을 기준으로 삼는다.

## 디자인 성격

Agent Dock은 agent-aware local editor shell이다.

화면은 고급 다크 개발 도구의 정제된 깊이감과 터미널의 선명한 상태 신호를 함께 가진다. 사용자는 repo, worktree, 파일, Git 상태, 에디터 탭, 터미널 세션이 한 화면에서 전환되는 느낌을 받아야 한다.

## 시각 원칙

* 배경은 거의 검정에 가까운 다크 톤을 사용한다.
* 주요 패널은 얇은 경계선과 약한 내부 하이라이트로 층을 만든다.
* 액센트는 인디고/보라와 터미널 그린을 함께 사용한다.
* 큰 면적의 색은 절제하고, 상태와 선택 표현에 선명한 색을 쓴다.
* 패널은 tmux나 로컬 IDE처럼 밀도 있게 배치한다.
* 장식은 제품 맥락을 강화하는 경우에만 사용한다.

## 색상 기준

* 기본 배경: `#06070a`, `#0b0d12`
* 패널 배경: `rgba(13, 16, 23, 0.86)`, `#10141d`
* 경계선: `rgba(125, 139, 255, 0.22)`, `rgba(92, 255, 130, 0.24)`
* 기본 텍스트: `#f4f7fb`
* 보조 텍스트: `#99a3b5`
* Modern Dark 액센트: `#7c7cff`, `#9b5cff`
* Terminal 액센트: `#5cff82`, `#d7ff72`
* 위험 상태: `#ff5f7a`

색상 token의 사용 상황은 `docs/design-color-tokens.md`를 따른다.

## 타이포그래피

* 제품명, 주요 헤드라인은 시스템 산세리프를 사용한다.
* 경로, 상태, 터미널, 코드, 세션 정보는 모노스페이스를 사용한다.
* 헤드라인은 크게 쓰되 화면 전체의 작업 밀도를 해치지 않는다.
* 버튼과 상태 라벨의 letter spacing은 0으로 둔다.

## 레이아웃

* 기본 구조는 왼쪽 세션/파일 맥락, 중앙 에디터, 오른쪽 상태/작업 맥락, 하단 터미널이다.
* 패널 안에 패널을 중첩해 장식하지 않는다.
* 반복 항목은 카드로 표현할 수 있지만 페이지 섹션 전체를 떠 있는 카드처럼 만들지 않는다.
* 화면 폭이 좁아지면 패널은 자연스럽게 세로로 쌓인다.

## 컴포넌트 감각

* 세션 목록은 선택 상태를 분명히 보여준다.
* 상태 라벨은 `[OK]`, `[SYNC]`, `~/repo` 같은 터미널 표현을 사용할 수 있다.
* 버튼은 작고 기능적인 모양을 기본으로 한다.
* 입력창을 흉내내는 요소는 프롬프트와 커서를 함께 보여줄 수 있다.
* 차트 대신 로그, 진행 바, 상태 라인 같은 텍스트 기반 표현을 우선한다.

## 효과와 움직임

* CRT scanline, glow, spotlight 효과는 약하게 사용한다.
* 텍스트와 UI의 가독성이 효과보다 우선한다.
* 깜빡이는 커서나 선택 표시처럼 제품 맥락이 있는 움직임을 사용한다.

## 접근성

* 텍스트 대비는 충분히 확보한다.
* 색만으로 상태를 구분하지 않고 라벨을 함께 사용한다.
* 작은 화면에서 긴 경로와 모노스페이스 텍스트가 넘치지 않게 줄바꿈과 축약을 적용한다.

## 적용 방식

새 UI를 만들 때는 이 문서를 먼저 확인한다.

색상을 적용할 때는 `docs/design-color-tokens.md`의 semantic token을 사용한다.

Codex 작업자는 `.codex/skills/modern-terminal-design` 스킬을 사용해 이 디자인 기준을 구현 지침으로 변환한다.
